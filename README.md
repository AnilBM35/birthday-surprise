# Birthday Surprise 💜

**A Birthday Quest** — a pixel-art birthday surprise web experience. A five-level night adventure:

1. 🎵 **Music gate** — an iPhone-style inline player for "your song"
2. 💌 **Birthday letter** — typewriter animation with Bible verses
3. 💘 **The choice** — a playful Yes/No page (the No button dodges you!)
4. 🌧️ **Memory rain** — catch falling photo & video memories
5. 🎂 **Finale** — a pixel-art scene with blowable candles, fireworks, and confetti

It's a single self-contained `index.html` (HTML + CSS + JS, no backend, no build step). Just open it in a browser.

## Demo version

This public repo is a **demo/template** version:

- The Memory Rain section uses placeholder demo cards instead of real photos and videos.
- Names are generic ("my love") — search the file for `my love` and make it yours.

## Make it yours

1. Replace the `data-src` / `data-poster` attributes on the `.memory-drop` buttons with your own photos and videos (or regular URLs).
2. Edit the letter text, the finale lines, and the Bible verses to fit your story.
3. Swap the music file and the pixel-art avatars for your own.
4. Deploy the folder as a static site (Vercel, Netlify, GitHub Pages…).
